# eSIM Vietnam

Статический русскоязычный сайт для https://esimvietnam.vercel.app. В браузере нет JavaScript, запросов к API, внешних шрифтов и трекеров. HTML, CSS и локальные WebP-фотографии.

## Запуск

Нужен Node.js 22 или новее. Установка зависимостей не требуется.

```powershell
npm run build
npm run check
npm start
```

Предпросмотр: http://127.0.0.1:4173. Готовые файлы находятся в `dist`.

## Vercel

Импортируйте этот репозиторий в проект `esimvietnam` на Vercel. Настройки уже записаны в `vercel.json`:

- Framework Preset: Other
- Build Command: `npm run build`
- Output Directory: `dist`
- Node.js: 22 или новее

Привяжите нужный адрес в настройках проекта. Canonical, Open Graph URL, sitemap и LLM-файлы используют `https://esimvietnam.vercel.app` из `site.config.json`. Для другого домена измените `url` или задайте `SITE_URL`. Переменная `TELEGRAM_URL` при необходимости переопределяет канал. Preview-развёртывания Vercel получают `noindex, nofollow` и запрет в robots.txt.

API-токен на Vercel **не нужен**. Сборка читает сохранённый каталог и не обращается к поставщику. Локальный `.env` исключён из Git; его не следует загружать на хостинг. Публикация на Vercel не выполнялась в рамках подготовки файлов.

## Тарифы

Запрос к указанному пользователем `/orders` выполнен один раз без токена и вернул HTTP 401. Согласно предоставленному OpenAPI это список заказов, а каталог находится в `/products`.

После получения доступа выполнен один GET к `/products?countries=VN&page=1&per_page=100&sort_by=price&sort_order=asc`. Получено 100 из 117 предложений; 47 с `country_code: VN` показаны на сайте. Региональные пакеты не показаны. Вторая страница не запрашивалась согласно требованию однократной загрузки. Сайт не заявляет полноту каталога.

В `data/tariffs.json` сохранены только данные продуктов и рекомендуемые розничные цены `price_retail_rub`. Партнёрские цены и токен не сохраняются в каталоге и публичной сборке. Для `billing_unit: day` явно указана оплата за день, диапазон срока и принцип расчёта. Условия ограничения скорости и раздачи берутся из API.

В `scripts/import-tariffs.mjs` предусмотрен импорт из локального `.env`; повторная загрузка блокируется, если снимок уже есть. Скрипт не запускается при сборке и просмотре сайта.

## Редактирование

Дополнение от 4 октября 2026: добавлены расчёты на 7, 14 и 30 дней, стоимость гигабайта, сравнение пакетов 5 ГБ по сроку и полная стоимость дневного безлимитного тарифа. Рекомендации выбираются из сохранённого каталога без повторного API-запроса. Есть отдельные инструкции для iPhone и Android и таблица диагностики. Все суммы в аналитических разделах вычисляются при сборке.

Для завершения коммерческой информации нужны настоящие сведения о продавце, поддержке, приёме оплаты, сроках выдачи и возврате. До их получения опубликован порядок согласования условий без вымышленных гарантий. Полевые тесты и личные скриншоты не имитируются. Данные об авторе не выдуманы. После публикации можно подтвердить сайт в Search Console и Яндекс Вебмастере через учётные записи владельца; эти сервисы пока не подключены.

- `site/index.html` — тексты и структура страницы, H1/H2/H3, FAQ и источники.
- `site/assets/style.css` — адаптивное оформление.
- `site.config.json` — домен, канал Telegram, дата обновления материала.
- `scripts/build.mjs` — статический вывод тарифов, SEO и текстовых файлов.
- `data/tariffs.json` — сохранённый каталог.

Генерируются `robots.txt`, `sitemap.xml`, `llms.txt`, дополнительный псевдоним `llm.txt`, `llms-full.txt` и страница 404. Разметка Schema.org: WebSite, WebPage и FAQPage. Разметка FAQ не гарантирует расширенное отображение в поиске. Заявлений о гарантированном SEO-результате нет.
